# Система сравнения текстов (Text Similarity Service)

Веб-приложение для загрузки текстовых файлов и сравнения их двумя методами:

1. **TF-IDF + косинусное сходство** — лексическая близость (совпадения слов)
2. **Эмбеддинги sentence-transformers + косинусное сходство** — семантическая близость (совпадения смысла)

Поддерживаются тексты на **русском, английском и китайском** языках.

## Стек

- **FastAPI** — веб-фреймворк, все эндпоинты в `main.py`
- **MongoDB** — учёт загруженных файлов и сохранение отчётов о сравнениях (коллекция `comparisons`)
- **Nginx** — проксирование запросов к FastAPI
- **Docker Compose** — три сервиса: `fastapi`, `mongo`, `nginx`
- **scikit-learn** — TfidfVectorizer и cosine_similarity
- **sentence-transformers** — модель эмбеддингов
- **jieba** — сегментация китайского текста (разбиение на слова без пробелов)
- **matplotlib** — тепловые карты сходства

## Мультиязычная обработка

### Проблема

Китайский текст не содержит пробелов между словами. TfidfVectorizer режет текст по
пробелам, поэтому весь китайский абзац превращается в один «токен», и сходство
получается бессмысленным. Кроме того, без явной кодировки чтение файлов в контейнере
может сломать не-ASCII символы.

### Решение

**1. Сегментация.** Функция `preprocess_for_tfidf()` в `main.py`:

- находит непрерывные последовательности иероглифов (CJK) регулярным выражением;
- режет их на слова через `jieba.lcut()`;
- склеивает всё пробелами в формат, который понимает TfidfVectorizer.

Русский и английский тексты проходят функцию без изменений.

**2. Приведение к нижнему регистру.** В `compute_tfidf_similarity()` перед
векторизацией применяется `.lower()` — для английских слов; у иероглифов регистра нет.

**3. Кодировка.** Все места чтения файлов в `main.py` открываются с явным
`encoding="utf-8"`, независимо от локали операционной системы и контейнера.

**4. Шрифты.** В Dockerfile устанавливаются шрифты Noto CJK:

```dockerfile
RUN apt-get update && apt-get install -y fonts-noto-cjk && rm -rf /var/lib/apt/lists/*
```

В `main.py` после импорта matplotlib задан список шрифтов: DejaVu Sans рисует
русский и английский, недостающие иероглифы подтягиваются из Noto Sans CJK SC —
на тепловых картах вместо квадратиков `□□□` отображаются нормальные символы:

```python
import matplotlib
matplotlib.use('Agg')
import matplotlib.pyplot as plt
matplotlib.rcParams["font.family"] = ["DejaVu Sans", "Noto Sans CJK SC"]
```

## Запуск

```bash
docker compose build fastapi
docker compose up -d
docker compose logs fastapi --tail 20   # проверить отсутствие ошибок
```

Интерфейс: http://localhost:8083

## Эндпоинты

| Метод | Путь | Назначение |
|---|---|---|
| POST | `/upload/` | загрузка текстового файла (multipart, поле `file`) |
| GET | `/files/` | список файлов с номерами и статусами |
| POST | `/compare/` | сравнение файлов: `numbers=1,2`, обе метрики в ответе, результат сохраняется в MongoDB |
| POST | `/heatmap/` | тепловая карта сходства (PNG) |

## Примеры команд

Загрузка файла:

```bash
curl -s -X POST -F "file=@uploads/test1.txt" http://localhost:8083/upload/
```

Список файлов:

```bash
curl -s http://localhost:8083/files/
```

Сравнение (обе метрики в ответе):

```bash
curl -s -X POST -F "numbers=1,2" http://localhost:8083/compare/ | python3 -m json.tool
```

## Выводы

1. **Два метода отвечают на разные вопросы.** TF-IDF измеряет совпадение слов,
   эмбеддинги — совпадение смысла. На парах «один смысл, разные языки» разрыв
   между метриками максимален: 0.000 против 0.968 (пара 11–12).
2. **Мультиязычность эмбеддинг-модели подтверждена экспериментально.** Все шесть
   межъязыковых пар показали 0.760–0.968 — модель распознаёт одинаковую семантику
   через языковой барьер. TF-IDF на всех межъязыковых парах — ровно 0.000.
3. **Языковой фактор виден и внутри TF-IDF.** Пары одного языка с одним смыслом
   дают низкий, но ненулевой TF-IDF (0.068–0.228) — общие служебные слова.
4. **Редакции одной сказки — зона согласия методов.** Толстой и Ушинский дают
   0.863 по TF-IDF (почти дословно совпадающая песенка Колобка) и 0.920–0.934
   по эмбеддингам: обе метрики подтверждают близость текстов.
5. **Контрольная пара подтверждает логику снизу.** Несвязанные русские тексты
   (1–2): TF-IDF 0.068, эмбеддинги 0.422 — нейросеть видит слабую общую тематику,
   хотя лексика не совпадает.
6. **Границы метода.** Триада «Колобок» (0.760–0.854) показала эмбеддинги ниже,
   чем триада «праздник Весны» (0.911–0.968): краткий пересказ насыщен деталями
   и именами, а короткие типовые тексты модели легче признают близкими.

## Сценарии для отчёта

| Сценарий | TF-IDF | Эмбеддинги |
|---|---|---|
| Один смысл, разные языки (10–12, 16–18) | около 0 | высокое |
| Одна сказка, разные редакции (13–15) | высокое | высокое |
| Близкие тексты внутри одного языка (6–7, 8–9) | низкое–умеренное | высокое |
| Несвязанные тексты (1–5) | низкое | низкое |

Сочетание двух метрик показывает, что лексическое и семантическое сходство —
разные величины: TF-IDF видит только совпадения слов, эмбеддинги — совпадения
смысла, в том числе между языками.
